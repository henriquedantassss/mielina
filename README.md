# Mielina by Quíron

Atlas 3D do sistema nervoso inteiro, central e periférico, com 592 estruturas e nomes em português.

Abra em: https://henriquedantassss.github.io/mielina/

Tudo cabe num arquivo só (`index.html`), que funciona sem internet depois de aberto.

## Créditos e licença do modelo

- Anatomia: **Z-Anatomy**, de Gauthier Kervyn e Marcin Zielinski (CC BY-SA 4.0), feito sobre o **BodyParts3D**, © The Database Center for Life Science (CC BY 4.0).
- Córtex cerebral: **Brain for Blender**, de Anderson M. Winkler (CC BY-SA 3.0), adaptado no Z-Anatomy.
- A conversão para o navegador partiu da versão 1.2.0 do Svitylo 3D Anatomy Atlas (pacote npm `@authorod/svitylo-3d-anatomy-data`).
- Esta versão simplifica e recolore as malhas. Os nomes em português e as fichas foram escritos para o Mielina. O modelo modificado segue a licença CC BY-SA 4.0.
- Bibliotecas: three.js (MIT) e meshoptimizer (MIT). Fontes: Unbounded, Figtree e Martian Mono (OFL).

Serve para estudo, não para diagnóstico.

A pasta `fonte/` tem os scripts que geram o `index.html`.
